Projeto de Estrutura de Dados 2
===============================

Esta atividade tem como objetivo investigar, de forma experimental, o comportamento de estruturas de dados e algoritmos fundamentais, 
estabelecendo relações entre conceitos como arrays, matrizes, algoritmos de ordenação, algoritmos de busca, manipulação de índices, 
estruturas de repetição (loops) e complexidade computacional. Mais do que compreender esses conceitos de maneira teórica, propõe-se aqui uma abordagem prática, 
na qual o desenvolvimento dos códigos é apenas o ponto de partida.
